Fonte dos dados

Este catálogo contém informações sobre os egressos e alunos ativos do Programa de Pós-Graduação em Computação Aplicada do Instituto Nacional de Pesquisas Espaciais. Foi atualizada em setembro de 2026. O catálogo contém também os egressos dos programas antecessores da PGCAP (em particular, Análise de Sistemas e Aplicações).

Usamos várias fontes de dados para criar este catálogo, entre elas, uma versão do controle acadêmico do INPE, a lista de teses e dissertações curada pela Biblioteca do INPE, os Currículos Lattes dos egressos e discentes e complementação manual.

O catálogo será atualizado manualmente em lotes, verificando sempre a consistência dos dados. Versões futuras podem incluir dados de outras fontes e medidas de qualidade/atualidade da informação.
