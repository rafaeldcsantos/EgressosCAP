Como este grafo foi extraído

As coautorias foram extraídas como arestas dirigidas, agregadas por publicação. Foram consideradas somente coautorias claramente identificadas por um ID Lattes válido de 16 dígitos. A partir da lista-base de egressos (A), esses IDs declarados diretamente em seus currículos formam a camada B de coautores diretos.

Os currículos da camada B foram lidos apenas para recuperar ligações internas entre A e B, sem expandir a rede novamente. Neste recorte pessoal, aparecem a pessoa central, seus coautores diretos e as ligações já registradas entre esses coautores. Os nomes são rótulos declarados nos currículos: não foram usados para identificar pessoas.

Use Forças (ForceAtlas2) para explorar agrupamentos, Por comunidades para separar grupos de colaboração e Radial para explorar as conexões de uma pessoa. Circular e Grade distribuem os nós regularmente; Concêntrico coloca as pessoas com mais coautores no centro. A pessoa selecionada aparece em magenta.

    Coautores no filtro atual

      O peso de cada ligação é o menor dos contadores quando o par aparece nos dois sentidos. Quando há apenas um sentido, usamos o contador disponível. A espessura usa uma escala logarítmica do peso, para tornar visíveis também as diferenças entre colaborações mais frequentes. Nomes de coautores não identificados no catálogo são substituídos pelo ID Lattes. A ausência de uma ligação não comprova ausência de colaboração.
